## Fixed paired procedure

Pair order is fixed as CLI R1, Desktop R1, CLI R2, Desktop R2, CLI R3,
Desktop R3. For each CLI attempt, launch a new `agy` process from that attempt's
empty directory. Confirm model/effort and the zero-token status line before the
prompt. Type exactly `hi` once, wait for the final response, capture the response
with the token summary, open `/usage`, capture the native quota display, and exit
without resuming or continuing the conversation.

Only the attempt directory and the intended surface change. Any model, effort,
settings hash, script hash, permission posture, built-in inventory, plugin, MCP,
skill, hook, account, or prompt change invalidates the affected attempt and
requires a replacement preregistration before continuing.
